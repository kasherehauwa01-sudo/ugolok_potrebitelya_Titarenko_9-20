# Альтернативный уголок потребителя

Статическая страница `index.html` для ИП Титаренко Олега Алимовича. Открывается непосредственно в браузере, без установки зависимостей. Адаптирована для телефона и печати через кнопку на странице. При печати раскрываются все памятки.

## Подтвержденные данные

- ИНН: 231113584561 — из предоставленного свидетельства.
- ОГРНИП: 319237500133923 — из предоставленного листа записи ЕГРИП.
- Регистрация: 16.04.2019; выдача листа записи: 17.04.2019.
- График: 09:00–20:00, без выходных — подтвержден заказчиком.

Структура приведена к прошлым проектам «Уютайм» и Куприяновой: продавец, документы, график, правовые документы, телефоны. Уведомления внизу страницы удалены по просьбе заказчика.

По просьбе заказчика добавлены оригиналы `assets/documents/inn.jpg` и `assets/documents/egrip.jpg`. В карточках отображаются миниатюры полного листа без обрезки; доступны открытие оригинала в новой вкладке и скачивание JPG. Файл ИНН.jpg — уведомление о постановке на учёт от 17.04.2019, а не ранее предоставленное свидетельство 2002 года. Данные карточки обновлены по приложенному уведомлению.

## Размещение

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). Либо разместите `index.html` на любом статическом хостинге. Загрузка файлов в GitHub сама по себе не включает Pages.
